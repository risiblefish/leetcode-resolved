## 这份要学 / 复习什么（薄预习）

> 来自预习卡：`npm run learn -- array-hash`

- **核心思想**：用 O(n) 的额外空间（Map/Set）把『查找/计数』从 O(n) 降到 O(1)。遍历时边读边把已经见过的信息存起来。
- **识别信号**（看到这些条件就该想到该套路）：
  - 题目要你判断『是否出现过』『两数之和』『分组』→ 哈希
  - 要求 O(n) 但暴力是 O(n²) → 用哈希/前缀和降复杂度
  - 需要统计次数/去重/求交集 → Map / Set
- **易错 / 边界**：
  - 空数组 / 单元素
  - 有重复元素时返回下标还是值
  - TS 里字符串不可变，改字符要先拆成数组
  - Map 的键是值语义（对象当键要注意引用）
- **本题专属**：**是 #242 的升级版** —— #242 只问「两个串是否异位词」（一次计数比对），本题问「一堆串怎么按异位词**分组**」→ 把「异位词」压缩成一个**可比较的键**。

## 我的思路（先写再做，哪怕写错）

**钩子：异位词排序后长得一样 —— 排序后的串当 key，桶里装原串。**

1. 每个串拆成字符数组 → 排序 → 拼回字符串，得到 key
2. `Map<string, string[]>`：key 已经有桶就 `push` 进去，没有就先建空桶再 `set`
3. 最后把 `Map.values()` 收集成答案

## 卡点（卡在哪 / 看了什么提示）

**算法侧**：没卡。「排序后当 key」秒想到，桶的 push 顺序也对。

**TS 侧（值得回看的两点）**：

1. 场上写的是 `if (map.has(key)) { map.get(key)!.push(str) }` —— **这里能跑通，恰恰是 PF-0004 的另一面**：
   `get` 拿到的虽然是**副本**，但桶是**数组（引用类型）**，`push` 改的是堆上那个数组 → 表里跟着变。
   （#242 那次栽的是 `number`：`cnt--` 只改了副本 → 表里没变。）
   更稳的写法是 `const bucket = map.get(key) ?? []` 然后 `set` 回去，不依赖 `!` 断言。
2. key 用的是 `[...str].sort().toString()` —— `Array.prototype.toString()` 等于 `join(",")`。
   本题只有小写字母，单字符元素下 `join(",")` 与 `join("")` **结果等价**（每个元素只有 1 个字符），所以是对的；换个「元素本身含逗号」的场景就会撞键。

## AI 复盘（AC 之后也值得看）

**好的**：

- 「异位词 → 可比较的键」这一步是本题的核心，直接想到了排序这种最朴素的规范化
- `Map<string, string[]>` 的类型标注写对了（值类型用 `!` 也没爆 any）
- 用一个 for 循环收集 `values()`，没在遍历中改表

**可改进**：

- `has` + `get!` 双查一次 → 两处规范化（透明披露）：
  - `const bucket = groups.get(key) ?? []` + `set` 回去（PF-0004 推荐的「读-改-写」，且不用 `!`）
  - `const ans = []` + 循环 → `return [...groups.values()]`（一行，且推断出 `string[][]`）
- 复杂度可以降到 **O(n · m)**：把「排序」换成**计数签名**（26 个小写字母的计数数组 → 用 `#` 分隔拼成 key），代价是 key 更啰嗦
- 也可以**按计数表分组**（key = 各字母出现次数的字符串）—— 和 #242 的计数表是同一条心法

**没应改**：

- 用「先建空桶再 set」处理首次出现，比「先塞 `[[str]]` 再特殊处理」更直白，保留

## 可改进点 / 标准要点

1. **钩子**：异位词排序后长得一样 → 排序后的串当 key
2. **核心心法**：把「一组串互为异位词」压缩成一个**可比较的键**（排序 key / 计数 key / 质数乘积 key）
3. **不变式**：同一个 key ⟺ 两个串字符计数完全相同 ⟺ 互为异位词
4. **三条 key 路线**：排序 `O(m log m)`（好写）｜26 字母计数 `O(m)`（更快）｜质数乘积（会溢出，仅作了解）
5. **边界**：空字符串（key 也是 `""`）、单字符、同一个串出现多次（同桶多个元素）、空输入 → `[]`
6. **反例**：`["aab","abb"]` 必须**分成两组**（抓「排序 key 写错/只比长度」）；`["ab","abc"]` 不是异位词
7. **TS 关联**：`[...str].sort().join("")` 而不是 `str.split("")` 也好，但注意 `toString()` 是 `join(",")`；[PF-0004](../../docs/knowledge/language/PF-0004-map-value-is-a-copy.md)（值是数组时 `push` 能改到表里，值是原始值时不能）；[PF-0007](../../docs/knowledge/language/PF-0007-type-position-empty-tuple.md)（泛型里 value 类型要写 `string[]`，别写 `[]`——那是空元组）
8. **复习时要达到**：闭卷写出排序 key 版 + 说清「为什么可以用排序后的串当 key」；能口头给出计数 key 版
