## 这份要学 / 复习什么（薄预习）

> 来自预习卡：`npm run learn -- array-hash`

- **核心思想**：用 O(n) 的额外空间（Map/Set）把『查找/计数』从 O(n) 降到 O(1)。遍历时边读边把已经见过的信息存起来。
- **识别信号**（看到这些条件就该想到该套路）：
  - 题目要你判断『是否出现过』『两数之和』『分组』→ 哈希
  - 要求 O(n) 但暴力是 O(n²) → 用哈希/前缀和降复杂度
  - 需要统计次数/去重/求交集 → Map / Set
- **易错 / 边界**：
  - 空数组 / 单元素
  - 有重复元素时返回下标还是值
  - TS 里字符串不可变，改字符要先拆成数组
  - Map 的键是值语义（对象当键要注意引用）
- **本题专属**：**Kadane 动态规划**（不是哈希）。心法只有一句：连续子数组一定**以某个位置结尾**，所以「以 i 结尾的最优」只依赖 i-1。**DP 里的第 1 道，拆分推进，别硬啃。**

## 我的思路（先写再做，哪怕写错）

**钩子：能接就接，拖后腿就另起炉灶；答案扫的过程中顺手取最大。**

1. `sum[i]` = **一定以 `nums[i]` 结尾**的最大连续子数组和（连续性靠这个「结尾」固定住）
2. 递推：`sum[i] = Math.max(sum[i - 1] + nums[i], nums[i])`
   —— 前面的和如果拖后腿（越加越小），就从 `nums[i]` **另起炉灶**
3. 答案不是 `sum[n-1]`，而是所有 `sum[i]` 里的最大值（子数组可以在任意位置结尾，用一个 `curMax` 边扫边取）

## 卡点（卡在哪 / 看了什么提示）

**算法侧**：没卡，递推式一次写对。场上注释里那句「连续子数组一定是以某个 `nums[i]` 结尾」说明**状态定义已经吃透**，这是 Kadane 的命门。

**TS 侧（真坑，值得单独记）：`new Array(n)` 静默变 `any[]`**

- `const sum = new Array(nums.length)` 推出的是 **`any[]`** —— 因为 TS 的 `ArrayConstructor` 签名就是 `new (arrayLength?: number): any[]`
- `strict` / `noImplicitAny` **不会报**！于是 `sum[0]` 是 `any`，`let curMax = sum[0]` 也变 `any`，一路传到返回值都不报错
- 已探测确认：`const a = new Array(3); const s: string = a[0];` 在 `tsc --noEmit` 下 **0 错**
- 修法：`new Array<number>(n)`（或 `Array.from({length: n}, () => 0)`、`new Array<number>(n).fill(0)`）
- 更彻底的修法：**别建数组**，用滚动变量（见可改进点）

## AI 复盘（AC 之后也值得看）

**好的**：

- 状态定义写在注释里，且定义得**准确**（「一定包含 `nums[i]`」）—— 这是 DP 最难的一步，做对了
- 答案取了「过程中的最大」而不是最后一项，避开了「结尾是负数」的经典翻车
- 初值用的是 `nums[0]`（不是 `0`）——**全负数用例自动正确**，很多人这里返 0 挂掉

**可改进**：

- **空间压到 O(1)**：`sum[i]` 只依赖 `sum[i-1]` → 一个变量滚起来即可
  ```ts
  let cur = nums[0], best = nums[0];
  for (let i = 1; i < n; i++) { cur = Math.max(cur + nums[i], nums[i]); best = Math.max(best, cur); }
  ```
- `new Array(n)` → **必须写泛型**（见卡点 / PF-0005）
- 变量名 `sum` 略泛（它是「以 i 结尾的最大和」而不是「和」）；`curMax` 可以叫 `best`，更贴语义
- 写法上 agent 只做了一处规范化（透明披露）：`new Array(nums.length)` → `new Array<number>(nums.length)`

**没应改**：

- 用 dp 数组而不是一上来就压成滚动变量，作为**第一次写 Kadane** 反而更好 —— 状态看得见，压缩是后面顺手的事

## 可改进点 / 标准要点

1. **钩子**：能接就接，拖后腿就另起炉灶；答案边扫边取最大
2. **状态与转移**：`dp[i] = max(dp[i-1] + nums[i], nums[i])`（含义：**以 i 结尾**的最大和）
3. **核心不变式**：`dp[i-1]` 一旦为负，它后面就永远是拖累 → 此时「另起炉灶」是最优（不需要额外判断，`max` 自己会选）
4. **答案位置**：`max(dp[0..n-1])`，不是 `dp[n-1]`（这是本题最容易错的第二处）
5. **全负数**：答案是最大的那个负数；**初值必须用 `nums[0]`**，用 `0` 会错
6. **空间压缩**：dp 只依赖前一项 → 滚动变量 O(1) 空间（r1 要达到）
7. **边界**：单元素；全负数；`[0]`；结尾一大截负数
8. **其他解法**（了解即可）：分治（跨中点最大值）、前缀和（记录最小前缀 → 一次扫描）
9. **TS 关联**：**PF-0005 `new Array(n)` 是 `any[]`**（strict 抓不到）；DP 数组建议 `new Array<number>(n)`
10. **复习时要达到**：闭卷写出 O(1) 空间版 + 口头说清「为什么 `dp[i-1] < 0` 就该另起炉灶」
