## 我的思路（先写再做，哪怕写错）

**钩子：值域限定 → 值当座位号；符号位占位，原值靠 abs 还原。**

题目给定：数组长度 n、元素取值 `1..n` → **值可以直接当索引**（座位号 = 值 - 1）。
既然要存的只有 1 bit（来过 / 没来过），就不用开 Set：
**把「来过」写在对应的座位上** —— 用正负号当那一 bit，原值用 `abs` 能还原。

- 第一圈：每个值 x「占座」—— `nums[|x| - 1]` 标成负数
- 第二圈：座位仍是正数 ⇔ 值 i+1 从没出现过 → 它就是答案

## 卡点（卡在哪 / 看了什么提示）

**算法侧**：第一次 AC 用的是 Set + 遍历（O(n) 空间），本题真正的考点是 **O(1) 额外空间**。

**最险的两个点**：
1. **答案必须等第二圈才能收** —— 第一圈跑完前标记不完整（卡上「两个循环的分工」那段）
2. **`Math.abs` 必须加** —— 座位可能已被前面的值标成负数；漏了就会 `idx = 负数 - 1` 越界。
   而 `strict` **不包含** `noUncheckedIndexedAccess`，`nums[-1]` 读写 tsc **完全不报错**（静默）

**r1 复习时真的在这里翻了车（本次卡点，debug 出来的）**：

第一圈写成了 `let idx = nums[i] - 1;`（少了 `Math.abs`）：

```ts
for (let i = 0; i < nums.length; i++) {
  let idx = nums[i] - 1;            // ❌ 忘了 nums[i] 可能已经被标成负数
  nums[idx] = -Math.abs(nums[idx]);
}
```

- **后果**：第一圈只要扫到一个已被标记过的位置，`idx` 就是**负数** → `nums[-3] = ...` 在 JS 里不是报错，而是给数组**加了一个名为 `"-3"` 的普通属性**（`Object.keys` 里能看到，`length` 不变）—— 该标的座位没标上，句号
- **最小翻车例**：`[2,1]` → 错版返回 `[1]`，正确答案 `[]`（1、2 都在场）。官方示例 1 `[4,3,2,7,8,2,3,1]` 也会直接给 `[1,5,6,7]`
- **为什么难自己看出来**：不报错、不抛异常，只是默默多算/少算；而且 `[2,2]`、`[3,3,3]` 这类用例**碰巧全过**（那些位置本来就该是正数）
- **修法**：两处都用绝对值 —— 读 `Math.abs(nums[i])`（你的最终版对），写 `-Math.abs(nums[idx])`（避免多次标记时符号翻转）
- **一句话不变式**：**下标是「位置」，只能用绝对值算；符号只是便签。**
- 同类 TS 陷阱参照题卡番外 C（`strict` 不管越界索引；`nums[-1]` 静默）

**教训（值得记）**：「越界不报错」使这类 bug 只能靠**跑**发现 —— 所以做题时要养成**跑一个「小到能心算」的例子**的习惯（`[2,1]` 这种），光看代码很难看出来。

## AI 复盘（AC 之后也值得看）

**好的**：
- 用 `nums[idx] = -Math.abs(nums[idx])` 而不是 `= -nums[idx]` —— **幂等**写法：同一座位标 N 次结果一样，不依赖「每个值只处理一次」这个隐式前提。这是自己想出来的，比卡上的模板更抗造
- 两个循环的分工踩对了：第一圈只标记，第二圈才收答案
- 第二圈用 `nums[i] > 0` 而不是 `!== 负数`，语义直白

**可改进**：
- 第一圈不关心下标，已改为 `for...of`（本 commit）；第二圈必须用下标（要算 `i+1`）
- 函数声明末尾 `};` 多余
- 该方法会**原地修改传入数组**（标记后就是 `[-4,-3,-2,...]`）：LeetCode 允许，但如果题目写了「不许修改输入」就不能用

**没应改**：
- O(n) + O(1) 已是理论最优

## 可改进点 / 标准要点

1. **钩子**：值域限定 → 值当座位号；符号位占位，原值靠 abs 还原
2. **三个前提（缺一不可）**：值域被限定（`1..n` 或 `0..n-1`）/ 数组可原地改 / 要存的只有 1 bit
3. **识别信号**：「长度 n、取值 `1..n`」「点名 O(1) 额外空间 + 数组可改」「找没出现/重复/缺失的数字」→ 原地标记
4. **反例**：「元素值任意大 / 有负数」→ 值域前提不成立，**退回 Set**
5. **两个循环的分工**：#442 那种「找重复」可以途中收答案；#448 这种「找没出现」**必须等第二圈**
6. **TS 坑**：`nums[-1]` 在 strict 下静默变 `undefined` / 本地加个 `"-1"` 属性，`tsc` 不报 —— 得自己保证 `idx >= 0`
