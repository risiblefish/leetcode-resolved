## 这份要学 / 复习什么（薄预习）

> 来自预习卡：`npm run learn -- array-hash`

- **核心思想**：用 O(n) 的额外空间（Map/Set）把『查找/计数』从 O(n) 降到 O(1)。遍历时边读边把已经见过的信息存起来。
- **识别信号**（看到这些条件就该想到该套路）：
  - 题目要你判断『是否出现过』『两数之和』『分组』→ 哈希
  - 要求 O(n) 但暴力是 O(n²) → 用哈希/前缀和降复杂度
  - 需要统计次数/去重/求交集 → Map / Set
- **易错 / 边界**：
  - 空数组 / 单元素
  - 有重复元素时返回下标还是值
  - TS 里字符串不可变，改字符要先拆成数组
  - Map 的键是值语义（对象当键要注意引用）
- **本题专属（非哈希套路）**：XOR 异或 —— 见 `ts/docs/knowledge/algorithm/pattern-array-hash.md` 番外 A

## 我的思路（先写再做，哪怕写错）

**钩子：成对互消，留下单身。**

XOR 是「配对消除器」：成对出现的数互相抵消，剩下的就是落单的。
三条性质（其余全是推论）：`a ^ a = 0`（抵消）、`a ^ 0 = a`（起点）、交换律 + 结合律（顺序无关）。
所以把所有数 XOR 到一起，配对的自消，剩下的就是答案。

## 可改进点 / 标准要点

1. **钩子**：成对互消，留下单身
2. **三条性质**：`a ^ a = 0` / `a ^ 0 = a` / 交换律 + 结合律；其余全是推论
3. **识别信号**：「所有数成对 + 一个落单」「出现奇数次 vs 偶数次」「要求 O(1) 额外空间 + 一次遍历」→ XOR
4. **TS 限制**：JS 位运算在 **32 位整数**上做。LeetCode 本题数据在 ±30000 内，安全；若题目出现 > 32 位整数就不能直接用
5. **边界**：`[1]`；落单是 `0`（别把 0 当「没找到」）；负数
6. **反例对照**：`[1,2,3,2,1]`（落单在中间，靠交换律仍正确）
