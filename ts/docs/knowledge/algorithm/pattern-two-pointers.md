# 预习卡 · 双指针

> **知识块**：算法 · 套路卡（pattern primer）　|　**pattern**：`two-pointers`　|　回看：`npm run learn -- two-pointers`

## 它是什么

用两个下标代替两层嵌套循环。两种形态：同向快慢指针（读写位置）、相向左右指针（从两端夹）。

## 核心思想

每一步移动都『排除掉一批不可能的答案』，从而把 O(n²) 降到 O(n)。关键是利用有序/单调这个前提。

## 考什么 / 学什么

考你能否识别『有序』这个可利用条件，以及推理该移动哪一边。

## TS 模板骨架（半成品）

```ts
let l = 0, r = nums.length - 1;
while (l < r) {
  const s = nums[l] + nums[r];
  if (s === target) return [l, r];
  if (s < target) l++;
  else r--;
}
```

## 常见变体

- 快慢指针：原地删除/去重/移动零
- 相向指针：有序两数之和、盛最多水
- 排序 + 固定一个 + 双指针：三数之和/四数之和
- 快慢判环、找中点（也是双指针）

## 易错 / 边界

- 三数之和去重要跳过相同值
- 循环条件是 l<r 还是 l<=r
- 快慢指针写位置不可回退
- 先排序会丢失原始下标（需要下标就别排序）

## 识别信号

- 有序数组 + 找一对/一段 → 左右指针
- 原地删除/过滤且要保持相对顺序 → 快慢指针
- 去重/排序后再找组合 → 排序 + 双指针
