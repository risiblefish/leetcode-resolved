# 预习卡 · 树与递归

> **知识块**：算法 · 套路卡（pattern primer）　|　**pattern**：`tree-recursion`　|　回看：`npm run learn -- tree-recursion`

## 它是什么

树本身就是递归结构：一棵树 = 根 + 左子树 + 右子树。二叉搜索树（BST）额外满足：左子树都小于根、右子树都大于根，因此中序遍历是升序。

## 核心思想

递归三步：①定义函数语义 ②终止条件（null） ③用左右子树的结果拼出当前答案。

## 考什么 / 学什么

考递归思维——信息可以通过『返回值 / 参数 / 全局变量』三种方式在递归里传递。

## TS 模板骨架（半成品）

```ts
function dfs(node: TreeNode | null): number {
  if (!node) return 0;
  const l = dfs(node.left);
  const r = dfs(node.right);
  return 1 + Math.max(l, r);
}
```

## 常见变体

- 前/中/后序遍历
- 深度 / 直径 / 平衡
- 路径和 / 最大路径和
- LCA（最近公共祖先）
- BST：验证、第 k 小、插入删除
- 由遍历序列构造树

## 易错 / 边界

- 返回值到底代表什么（单值 vs 信息包）
- 需要跨子树聚合时用全局变量或返回多个值
- 验证 BST 不能只比较父子，要用上下界

## 识别信号

- 树/二叉树/子树/路径/深度 → 递归 DFS
- BST + 有序 / 第 k 小 → 中序遍历
- 要按层处理 → BFS
