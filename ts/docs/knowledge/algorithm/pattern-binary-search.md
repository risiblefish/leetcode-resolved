# 预习卡 · 二分查找

> **知识块**：算法 · 套路卡（pattern primer）　|　**pattern**：`binary-search`　|　回看：`npm run learn -- binary-search`

## 它是什么

在有序或单调的空间里，每次比较后排除一半。不只是『在有序数组里查数』，也包括对答案二分。

## 核心思想

维持循环不变量（比如闭区间 [lo, hi] 始终是候选范围），每次排除一半 → O(log n)。

## 考什么 / 学什么

考边界控制（最容易写死循环/越界），以及能否发现『答案具有单调性』。

## TS 模板骨架（半成品）

```ts
let lo = 0, hi = n - 1;
while (lo <= hi) {
  const mid = lo + ((hi - lo) >> 1); // 防溢出
  if (ok(mid)) hi = mid - 1; // 找左边界
  else lo = mid + 1;
}
return lo;
```

## 常见变体

- 精确查找 / 插入位置
- 找第一个/最后一个满足条件的位置
- 旋转排序数组
- 二分答案（最小速度、最小容量）

## 易错 / 边界

- mid 计算用 lo+(hi-lo)/2 防溢出
- lo/hi 更新写错导致死循环
- 返回 lo 还是 mid 还是 -1
- 边界条件是 <= 还是 <

## 识别信号

- 有序 + 查找/插入位置 → 二分
- 题目问『最小能满足的 x』且可行性随 x 单调 → 二分答案
- 旋转/峰值/第一个出错版本 → 二分变体
