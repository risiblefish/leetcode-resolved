# 预习卡 · 链表

> **知识块**：算法 · 套路卡（pattern primer）　|　**pattern**：`linked-list`　|　回看：`npm run learn -- linked-list`

## 它是什么

链表由节点和指针串起来，不能随机访问；插入/删除只改指针 O(1)，但访问第 k 个要 O(k)。

## 核心思想

用哑结点 dummy 消除头节点特判；改指针前一定先保存 next；用画图代替脑补。

## 考什么 / 学什么

考指针操作的严谨与细心，几乎是纯『手写基本功』题。

## TS 模板骨架（半成品）

```ts
let prev: ListNode | null = null;
let cur = head;
while (cur) {
  const nxt = cur.next;
  cur.next = prev;
  prev = cur;
  cur = nxt;
}
return prev;
```

## 常见变体

- 反转（整体 / k 个一组 / 区间）
- 合并两个/多个有序链表
- 删除倒数第 n 个（哑结点 + 快慢）
- 判环 / 找环入口 / 找中点
- LRU（双向链表 + 哈希）

## 易错 / 边界

- 先改指针再保存 next 导致丢链
- 删除头节点没特判（用 dummy）
- TS strict 下 null 检查
- 快慢指针循环终止条件

## 识别信号

- 反转 / 合并 / 删除节点 / 找倒数 → 哑结点 + 双指针
- 判环 / 找中点 → 快慢指针
- 需要 O(1) 插删且最近最少使用 → 哈希 + 双向链表（LRU）
