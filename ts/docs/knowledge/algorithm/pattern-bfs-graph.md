# 预习卡 · BFS 与网格图

> **知识块**：算法 · 套路卡（pattern primer）　|　**pattern**：`bfs-graph`　|　回看：`npm run learn -- bfs-graph`

## 它是什么

BFS 用队列一层层向外扩展；DFS 用递归或栈一条路走到底；图/网格遍历都必须用 visited 防重复。

## 核心思想

BFS 天然求『无权图最短步数』（因为按层扩展）；『入队即标记 visited』避免重复入队；网格用四方向数组 + 边界判断。

## 考什么 / 学什么

考把现实问题建模成图/网格并选对遍历方式（最短用 BFS、连通块用 DFS/BFS）。

## 常见变体

- 连通块（岛屿数量/面积）
- 最短路（二进制矩阵/单词接龙）
- 多源 BFS（腐烂的橘子 / 01 矩阵）
- 拓扑排序（课程表）
- 克隆图

## 易错 / 边界

- 入队时机：入队时就标记，别等出队
- 网格边界与越界判断
- 层数统计用 size 快照
- 用数组当队列时别用 shift（O(n)），用 head 指针

## 识别信号

- 网格中求最短路径/最少步数/腐烂时间 → BFS
- 求连通块个数/面积 → DFS/BFS + visited
- 依赖顺序 / 能否完成 → 拓扑排序
- 克隆/遍历整张图 → 邻接表 + visited
