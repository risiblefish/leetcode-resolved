# 手写 drill · 手写二分模板（精确 / 左边界 / 右边界）

> **知识块**：算法 · 手写基本功（drill，闭卷）　|　**归属 pattern**：binary-search

## 要点

- 闭区间模板：while(lo<=hi)，mid = lo+((hi-lo)>>1)
- 找左边界：等于时收缩右界 hi=mid-1；找右边界：等于时 lo=mid+1
- 二分答案：把『可行性随 x 单调』的问题转成对答案二分
