# 预习卡 · 栈与队列

> **知识块**：算法 · 套路卡（pattern primer）　|　**pattern**：`stack-queue`　|　回看：`npm run learn -- stack-queue`

## 它是什么

栈是后进先出（LIFO），队列是先进先出（FIFO）。单调栈在入栈时弹掉『破坏单调性』的元素，是栈的进阶用法。

## 核心思想

栈擅长处理『最近的、可回退的』嵌套与配对；单调栈把『找下一个更大/更小』从 O(n²) 降到 O(n)。

## 考什么 / 学什么

考你对嵌套/配对结构的识别，以及单调栈的『存下标、弹栈算距离』套路。

## TS 模板骨架（半成品）

```ts
const st: number[] = [];
for (let i = 0; i < nums.length; i++) {
  while (st.length > 0 && nums[st[st.length - 1]] < nums[i]) {
    const j = st.pop()!; // i 就是 j 右边第一个更大的下标
  }
  st.push(i);
}
```

## 常见变体

- 括号匹配 / 表达式求值
- 单调栈：下一个更大、每日温度、柱状图矩形
- 辅助栈：最小栈
- 双端队列：滑动窗口最大值

## 易错 / 边界

- 单调栈存下标还是存值（要算距离就存下标）
- 循环数组要遍历两遍并取模
- 栈空判断，避免 pop 越界

## 识别信号

- 遇到『下一个更大元素 / 柱状图最大矩形 / 每日温度』→ 单调栈
- 括号匹配、嵌套结构、逆序处理 → 栈
- 需要 O(1) 取最小/最大，并支持 push/pop → 辅助栈
