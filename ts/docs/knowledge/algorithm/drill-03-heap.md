# 手写 drill · 手写小顶堆 + 堆排序

> **知识块**：算法 · 手写基本功（drill，闭卷）　|　**归属 pattern**：heap-greedy

## 要点

- 堆是完全二叉树，用数组表示：节点 i 的左孩子 2i+1、右孩子 2i+2、父 (i-1)/2
- 上浮 siftUp：新元素与父比较，小了就换，直到不需要换
- 下沉 siftDown：根与较小/较大孩子换，直到父子有序
- 堆排序：先原地建堆 O(n)，再反复把堆顶交换到末尾并收缩堆 O(n log n)
