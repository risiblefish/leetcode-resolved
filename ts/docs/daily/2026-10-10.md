## 接下来就一件事：复习（8 道）

**复习 = 闭卷重写**，三步：

1. 只读 `ts/problems/<题号>-<英文名>/notes.md` 的「**可改进点 / 标准要点**」一节
2. 关掉 notes，**闭卷**重写 `solution.ts`
3. `npm test` 全绿后：

```bash
cd ts
npm run solve -- <题号> --min <这次花了多少分钟>
```

> `solve` 会自动 git 提交并记下复习日期，**只有它认的提交才算进复习曲线**（`+1 → +3 → +7 → +15 → +30 → +60` 天）。
