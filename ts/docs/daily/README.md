# 今日任务文档（daily）

> 每次**新会话**的起点。AI 先问你是否起文档，**同意后**用 `npm run day` 生成骨架，AI 补全「今日主题 / 讲解」，你练完回填反馈，收尾时 AI 据今日情况更新路线。

## 一天的样子

```
新会话：「今天做什么？」
  ↓
AI 读 ROADMAP / STATE / 最近 daily / git log → 判断今天练什么
  ↓
AI 先问「要起今日任务文档吗？」→ 你同意（可顺便定题量 / 换类型）
  ↓
npm run day            # 生成 docs/daily/<日期>.md（今日题 + 复习 + 留白）
  ↓
AI 补全：今日主题 / 今日讲解 / 每题识别信号
  ↓
你去 LeetCode 练 → 回来给反馈
  ↓
AI 把反馈 / 卡点 / 讨论补进文档留白（顺利就不硬写）
  ↓
收尾：回填「复盘 & 对计划的调整」→ 更新 ROADMAP / STATE → 提交
```

## 文档结构

| 区块 | 谁填 | 说明 |
|------|------|------|
| 今日主题 | AI | 一句话：今天练什么、为什么是它 |
| 今日学习内容（讲解） | AI | 5–10 分钟能读完的薄讲解 + TS 模板 + 易错边界（不给完整题解） |
| 可选热身 | 脚本 | 未完成的手写 drill |
| 今日要做的题 | 脚本 | 新题（题号 / 中英文名 / 难度 / 链接 / 建目录命令） |
| 练习过程 · 反馈与讨论 | 用户 + AI | 卡在哪、怎么解决；**顺利就不必硬写** |
| 今日要复习的题 | 脚本 | 到期复习（Ebbinghaus），闭卷重写 |
| 复盘 & 对计划的调整 | AI | 太轻松→加量/进阶；吃力→**主动问**是否放慢加深（例：3 次→5 次），确认后更新路线 |

## 命令

```bash
npm run day                    # 默认 plan.dailyMin(2) 道新题 + 到期复习
npm run day -- --units 1       # 今天累
npm run day -- --units 4       # 状态好
npm run day -- --pattern dp    # 专攻某类型
npm run day -- --force         # 覆盖已存在的今日文档（慎用）
```

> 已有同名文档时**不会覆盖**，AI 直接在原文件上补全 / 回填。
