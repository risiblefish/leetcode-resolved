|---|---|---|
| #189 轮转数组 | 「整体右移 k 位」+ 要求 O(1) 额外空间 | **三次翻转**：全翻 → 翻前 k → 翻后 n-k |
| #49 字母异位词分组 | 一堆字符串要**分组**，组内互为异位词 | 排序后的字符串当 **key**（异位词排序后长得一样） |
| #56 合并区间 | 给一堆区间，要求合并重叠 | **按左端点排序** → 扫一遍，能接上就延右端，接不上就开新区间 |
| #53 最大子数组和 | 「连续子数组」+ 最大/最小和 | **Kadane**：到当前位置的最优 = `max(x, 前面最优 + x)`（为负就另起炉灶） |
| #128 最长连续序列 | 无序数组求**最长连续序列长度**，要求 O(n) | 全塞 `Set`；**只从「没有前驱的数」起跳**，避免重复扫描 |
| #238 除自身以外数组的乘积 | 每个位置要「其他所有数的积」，不许用除法 | **左右前缀积两趟**：左往右攒前缀，右往左攒后缀，相乘 |
| #347 前 K 个高频元素 | 出现次数前 K 名 | `Map` 计数 → **桶排序**（下标 = 频次）或最小堆 |

**易错边界（先记着，做题时验证）**：

- #189：`k` 可能大于 `n` → 先 `k %= n`；`k === 0` 直接返回
- #56：区间**端点相接**（`[1,4]` 接 `[4,5]`）算重叠；排序要动副本，别改入参
- #53：全是负数时答案是「最大的那个负数」，不是 0（`best` 初值用 `nums[0]`）
- #128：连续指**数值**连续（1,2,3），不是下标连续；重复值要去重
- #238：前缀/后缀数组的首尾是乘法单位元 `1`；不能有 0 陷阱
- #347：题目保证答案唯一；`k` 恒有效

#### 3. #56 合并区间 / Merge Intervals（Medium · 必做）

#### 4. #53 最大子数组和 / Maximum Subarray（Medium · 必做）

- 链接：https://leetcode.cn/problems/maximum-subarray/
- 识别信号：连续子数组 + 最大和 → 一遍扫描、为负就重开
- 我的思路（先写再做）：`sum[i]` = **一定以 `nums[i]` 结尾**的最大和；`max(sum[i-1]+x, x)`；答案边扫边取 max
- 结果：☐ 卡住　☑ **AC**　☐ 看了题解

- 转正：`ts/problems/0053-maximum-subarray/`（7 例测试）· 空间 O(n)，r1 要达到 O(1) 滚动版
