# 手写 drill · 手写归并排序（分治 + merge，顺带求逆序对）

> 类型：手写基本功（闭卷）  ·  归属 pattern：advanced-mixed

## 要点

- 分：从中间切开递归；治：把两个有序段合并
- merge 需要额外 O(n) 空间；稳定排序
- 在 merge 时统计『右边先于左边被取走』的次数 = 逆序对
