# 预习卡 · 动态规划（拆分推进）

> 类型：`dp`  ·  随时回看：`npm run learn -- dp`

## 它是什么

把问题拆成『重叠子问题』，用一张表把子问题的答案记下来，避免重复计算。本质是带记忆的递归。

## 核心思想

四步：①定义 dp 状态的含义（最难）②写转移方程 ③确定初始化 ④确定遍历顺序。建议先写记忆化递归，再改自底向上。

## 考什么 / 学什么

考状态设计能力，不是背题。DP 题千变万化，但套路就这四步。

## TS 模板骨架（半成品）

```ts
// 记忆化递归（推荐先写这个）
const memo = new Map<number, number>();
function f(i: number): number {
  if (i <= 1) return i;
  if (memo.has(i)) return memo.get(i)!;
  const v = f(i - 1) + f(i - 2);
  memo.set(i, v);
  return v;
}
```

## 常见变体

- 线性 DP（爬楼梯/打家劫舍）
- 子序列（LIS / LCS / 编辑距离）
- 背包（0/1 与完全）
- 区间 DP
- 树形 DP
- 股票系列 / 状态机 DP

## 易错 / 边界

- 状态定义含糊 → 转移推不出来
- 初始化与边界（dp[0] 是什么）
- 01 背包容量倒序、完全背包正序
- 不要一次学太多，DP 专题必须拆开、别连续硬啃

## 识别信号

- 求最大/最小/方案数 + 有重叠子问题 → DP
- 能写出递归但有大量重复计算 → 加 memo
- 涉及两个序列对比 → 二维 DP
