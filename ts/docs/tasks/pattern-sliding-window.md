# 预习卡 · 滑动窗口

> 类型：`sliding-window`  ·  随时回看：`npm run learn -- sliding-window`

## 它是什么

一个可伸缩的区间 [l, r]，在移动过程中维护区间内的统计量（和、频次表、不同元素数）。

## 核心思想

右界负责扩张、左界负责收缩，每个下标最多进出窗口一次 → 总复杂度 O(n)。

## 考什么 / 学什么

考你能不能识别『连续子串/子数组』并把它转化成维护窗口状态。

## TS 模板骨架（半成品）

```ts
let l = 0;
const cnt = new Map<string, number>();
for (let r = 0; r < s.length; r++) {
  // 把 s[r] 加入窗口
  while (/* 窗口不满足条件 */) {
    // 把 s[l] 移出窗口
    l++;
  }
  // 此时窗口合法，更新答案
}
```

## 常见变体

- 定长窗口（先进满再滑动）
- 可变长窗口（最长/最小）
- 恰好 K：用『至多 K』减去『至多 K-1』
- 滑动窗口最大值（单调双端队列）

## 易错 / 边界

- 先扩后缩 vs 先缩后扩的答案更新时机
- 字符计数移出时要清理 0 计数
- 窗口左界移动用 while 而不是 if

## 识别信号

- 题目问『连续子数组/子串』的最大/最小/最长 → 滑动窗口
- 关键词：满足某条件、至多 K、恰好包含、连续
- 窗口内容可用计数表示（字符数、不同元素数）
