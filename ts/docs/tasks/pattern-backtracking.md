# 预习卡 · 回溯

> 类型：`backtracking`  ·  随时回看：`npm run learn -- backtracking`

## 它是什么

在『决策树』上做 DFS：每层做一个选择，进入下一层递归，返回时撤销选择。

## 核心思想

路径 path + 选择列表 + 结束条件。组合用 start 往后走，排列用 used 标记；排序后同层跳过重复值来去重。

## 考什么 / 学什么

考你能否把『枚举所有方案』系统地写成递归，并用剪枝砍掉无效分支。

## TS 模板骨架（半成品）

```ts
const res: number[][] = [];
function dfs(start: number, path: number[]) {
  if (/* 结束条件 */) { res.push([...path]); return; }
  for (let i = start; i < nums.length; i++) {
    if (i > start && nums[i] === nums[i - 1]) continue; // 去重
    path.push(nums[i]);
    dfs(i + 1, path);
    path.pop(); // 撤销选择
  }
}
```

## 常见变体

- 子集 / 子集 II
- 组合 / 组合总和 / 组合总和 II
- 全排列 / 全排列 II
- 分割（回文串分割）
- 棋盘（N 皇后、数独）
- 网格搜索（单词搜索）

## 易错 / 边界

- 加入结果要拷贝 [...path]，否则是引用
- 组合用 start、排列用 used，别混
- 去重条件 i>start && nums[i]===nums[i-1]
- 能剪枝就剪枝（比如剩余和不够）

## 识别信号

- 求所有方案 / 所有组合 / 所有排列 / 分割方案 → 回溯
- N 皇后、数独、括号生成 → 回溯 + 剪枝
- 关键词：枚举所有可能、返回全部结果
