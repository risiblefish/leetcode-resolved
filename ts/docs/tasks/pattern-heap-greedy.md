# 预习卡 · 堆与贪心

> 类型：`heap-greedy`  ·  随时回看：`npm run learn -- heap-greedy`

## 它是什么

堆是完全二叉树，通常用数组表示，能在 O(log n) 内插入/删除，O(1) 取极值。贪心是每一步都取当前看起来最优的选择。

## 核心思想

堆靠上浮/下沉维持父子序；贪心要靠排序 + 一个『可证明』的局部最优选择（说不清为什么就可能是错的）。

## 考什么 / 学什么

考『Top K / 合并 / 调度』用堆，『区间 / 跳跃 / 股票』用贪心，以及贪心的正确性直觉。

## TS 模板骨架（半成品）

```ts
// JS 没有内置堆，常用排序/数组近似；手写堆见 drill-heap
const a = [...nums].sort((x, y) => x - y);
// 或维护一个大小不超过 k 的集合，每次去掉最差的
```

## 常见变体

- Top K（小顶堆 / 快速选择）
- 合并 k 个有序链表/数组
- 双堆求数据流中位数
- 区间贪心（按结束时间排序）
- 跳跃游戏（维护最远可达）
- 股票/加油站

## 易错 / 边界

- 堆的父子索引与 siftDown 终止条件
- 贪心必须能说清为什么局部最优导出全局最优
- 区间题排序键选开始还是结束
- JS 无内置堆，需手写或排序近似

## 识别信号

- 第 K 大/前 K 个高频 → 堆
- 合并 k 个有序 → 堆
- 区间调度 / 找最少数量 / 能否到达 → 排序 + 贪心
