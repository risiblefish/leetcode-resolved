# 预习卡 · 综合冲刺与高频

> 类型：`advanced-mixed`  ·  随时回看：`npm run learn -- advanced-mixed`

## 它是什么

综合运用：前缀和/差分把区间操作 O(1) 化，位运算找巧解，设计题（Trie/LRU）考结构组合，分治（快排/归并）考递归组织。

## 核心思想

前缀和 pre[i+1] = pre[i] + nums[i]，区间和 = pre[r+1]-pre[l]；位运算 n&(n-1) 清零最低位、异或抵消重复。

## 考什么 / 学什么

考限时下的综合实现能力，接近周赛节奏（前两题要又快又稳）。

## TS 模板骨架（半成品）

```ts
const pre = new Array(nums.length + 1).fill(0);
for (let i = 0; i < nums.length; i++) pre[i + 1] = pre[i] + nums[i];
// 区间 [l, r] 的和：
const sum = pre[r + 1] - pre[l];
```

## 常见变体

- 前缀和 + 哈希（和为 K）
- 差分（区间批量加减）
- 位运算（只出现一次、状态压缩）
- 设计（Trie / LRU / LFU / 中位数）
- 分治（快排 / 归并 / 逆序对）
- 单调栈（接雨水 / 最大矩形）

## 易错 / 边界

- 前缀和下标偏移（长度 n+1）
- 位运算运算符优先级低，要加括号
- 递归深度过大会栈溢出
- 设计题别漏更新内部状态

## 识别信号

- 频繁求区间和 → 前缀和
- 只出现一次 / 位计数 / 子集枚举 → 位运算
- 实现缓存 / 前缀树 → 设计题
- 周赛前 2 题通常是数组/哈希/字符串的快速实现
