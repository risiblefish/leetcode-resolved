# Guides · 操作指南

把「每天开始学习」和「封版提交」两件事，从 `AGENTS.md` 里单独拎出来，照着做即可。
参考同款组织：`video-lru/docs/guides`、`mathfun/docs`、`memo-palace/src/docs/core`。

| 指南 | 什么时候用 |
|---|---|
| [start-task.md](start-task.md) | 用户说「今天做什么 / 起 task / 开始练习」→ 起今日任务、写讲解、给清单 |
| [commit-guide.md](commit-guide.md) | 一次 task / 一天收尾 → 封版提交 |

- 总记忆：仓库根 `AGENTS.md`（每次会话自动加载）。
- 每日会话 SOP（AI 侧路由 + 红线）：`.agents/skills/daily-study/SKILL.md`。
- 产物：`ts/docs/daily/<日期>.md`。
